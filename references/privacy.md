# 隐私和数据安全

报名数据有姓名、学号、邮箱、微信号、年龄、付款截图，按下面的规矩处理：

- **不进仓库**：真实的 CSV、附件 zip、`out/`、凭证图都不提交到任何 git 仓库（`.gitignore` 已经排除了 `out/`、`data/`、`*.zip`）。示例只用 `make_sample.py` 生成的虚构数据。
- **不进聊天**：给用户汇报时说人数和问题，不要整段贴出名单、邮箱、手机号。需要指认某个人时用编号 + 姓名。
- **最小化**：签到页、抽奖页只带必要字段（`render.py` 已裁剪）；总表页不需要的列（如缴费结果）就别放进默认列，必要时在生成时去掉。
- **默认私有**：页面发布为私有，只分享给需要的人；公开链接意味着任何拿到链接的人都能看到名单。
- **二维码**：群二维码有有效期，写进 `after_confirm.expires` 提醒现场人员；换码后重新生成页面。
- **活动结束**：问用户要不要删除带个人信息的页面和文件。
