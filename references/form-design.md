# 报名表设计

好的报名表能省掉后面一半的整理工作。设计时按下面清单过一遍，然后把题目写成和 `event.json` 的 `columns` 对得上的样子。

## 推荐题目（按顺序）

| # | 题目 | 题型 | 为什么 |
|---|---|---|---|
| 1 | 您的姓名 | 填空 | 写明「请填中文全名」或「与证件一致」，否则会出现昵称、英文名混用 |
| 2 | 您的学校 / 单位 | 单选 + 其他 | 用单选减少写法不一致 |
| 3 | 您的学号 / ID | 填空 | **写一个格式示例**（如 `ab123`），否则一定有人填成邮箱；这是去重的主键 |
| 4 | 年级 / 身份 | 单选 | |
| 5 | 您的邮箱 | 填空 | 写明后缀示例；脚本会检查后缀拼错 |
| 6 | 微信号 / 手机号 | 填空 | 现场联系、拉群都要用，事后补很麻烦 |
| 7 | 是否已满 18 岁 | 单选 是/否 | 酒水、保险需要 |
| 8 | 交通（如去程 / 返程大巴） | 每段单独一题 是/否 | 分开问才能统计各自人数、发现「只坐单程」 |
| 9 | 票种 | 单选 | 选项里写清截止时间和价格；工作人员票单独一个选项 |
| 10 | 上传缴费凭证（门票 + 交通） | 文件上传，允许多张 | 提示「请上传**转账成功**页面截图，不是确认页」 |
| 11 | 优惠码（如有） | 填空 | 单独一题，别让人写进备注 |
| 12 | 过敏源 / 饮食 | 填空 | |
| 13 | 活动相关意向（如走秀、表演） | 单选 1-5 | 方便现场组织 |
| 14 | 其它说明 | 填空 | |

小贴士：
- 是/否题统一用「是 / 否」两个选项，脚本能直接识别；腾讯问卷导出的「A.是」前缀会自动去掉。
- 允许重填（修改答案）时，导出会出现同一个人多份提交；脚本按学号/邮箱保留最新一份并标出改了什么。
- 收款方式写在表单开头，包括收款人姓名，方便核对凭证。

## 开头文案

报名表开头 2-4 句即可，口吻像身边朋友，带几个 emoji，说清三件事：**是什么活动、什么时候在哪、填完要做什么**。给用户准备短 / 中 / 长三个版本挑选。

示例（虚构）：
> 🎉 秋季派对来啦！11 月 15 日晚，音乐、游戏、抽奖一个不落 🎶✨
> 填完这张表 + 上传付款截图，就算报名成功啦～有问题随时找组织者 💬

避免：长篇规则、法律条款式语言（放到表单末尾或单独链接）。

## 导出

**腾讯问卷**
1. 后台「数据 → 下载数据 → CSV」，得到报名表 CSV（时间是北京时间）。
2. 有上传题的话，「下载附件」得到 zip，文件名形如 `<编号>_q<题号>_<题目>_<原文件名>`。CSV 里的附件链接需要登录才能打开，所以一定要下载 zip。
3. 两个文件都交给 Claude；脚本直接读 zip，不用解压。

**Google Form**
回复表格「文件 → 下载 → CSV」。上传题的文件在 Google Drive 的表单文件夹里，整个文件夹下载成 zip；文件名里没有提交编号，需要把 `attachments.file_pattern` 改成能从文件名认出人的规则（例如表单里让大家把截图命名为学号）。

**其它**
任何 CSV / xlsx 都可以，只要第一行是表头。
